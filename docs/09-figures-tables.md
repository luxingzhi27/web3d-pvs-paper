## 2. 符号与数据流

| 符号 | 含义 |
|---|---|
| $u_i$ | 目标可独立剔除单元 |
| $z_i,z_j\in\mathbb R^{32}$ | 目标与来源单元的局部几何描述符 |
| $e_{ijk}\in\mathbb R^8$ | 目标、来源与方向锚点对应的关系特征 |
| $A_i\in\mathbb R^{12\times7}$ | 十二个方向锚点上的七维原始响应 |
| $\Phi\in\mathbb R^{12\times4}$ | 固定一阶方向基矩阵 |
| $F_i=\Phi^+A_i\in\mathbb R^{4\times7}$ | 方向生存场系数 |
| $\boldsymbol\omega,\ell$ | 从目标指向查询点的单位方向及世界距离 |
| $\rho_i,r$ | 目标单元尺度与水平圆盘半径，二者分开记号 |
| $s_i\in\mathbb R^4$ | 中心、最大、平均、最小生存响应 |
| $q_i\in\mathbb R^{16}$ | 相机、观察区域和目标相对几何构成的查询特征 |
| $\xi_i,\tau$ | 可见性 logit 与冻结决策阈值 |

离线共享编码器同时为目标与来源单元生成描述符。关系编译器联合 $z_i,z_j,e_{ijk}$ 产生 $A_i$，固定投影产生 $F_i$。紧凑资产包含 $z_i,F_i$ 及必要元数据，共享预测头权重单独计入运行时资产。

在线输入分为三条路径：

$$
z_i\longrightarrow\text{预测头},
$$

$$
(F_i,\text{支持点},\text{目标元数据})\longrightarrow s_i\longrightarrow\text{预测头},
$$

$$
(\text{相机},\text{圆盘区域},\text{目标元数据})\longrightarrow q_i\longrightarrow\text{预测头}.
$$

$q_i$ 与 $s_i$ 并行产生；池化特征与尺寸比例采用拼接而非数值相加。实线表示计算依赖，跨离线—在线边界的虚线表示资产传输或读取。简单网络以编码器、编译器和预测头表示，不逐层展开线性层与激活。

## 4. 图 2——整体架构

**位置：** 第 4.1 节；第 5 节复用在线分支。

**构成：** 单元几何、共享几何编码、关系编译、区域解析查询和可见性预测。紧凑资产汇聚离线结果，$z_i$ 和 $F_i$ 分别连接预测头与解析求值器。相机、圆盘与目标元数据连接查询几何分支。

**图注：** GCOF-PVS 的离线编译与在线查询。共享编码器生成 $z_i\in\mathbb R^{32}$，关系编译器生成方向响应 $A_i\in\mathbb R^{12\times7}$，经固定投影得到 $F_i\in\mathbb R^{4\times7}$。客户端读取紧凑资产，在水平圆盘的九个支持点上解析求值，形成 $s_i\in\mathbb R^4$。相机、观察区域与目标相对几何构成 $q_i\in\mathbb R^{16}$；预测头联合 $z_i,s_i,q_i$ 输出单元分数，用于区域过滤和渐进式排序。九个支持点仅用于解析计算，不产生额外渲染视图。

## 5. 图 3——方向生存场构建与区域查询

**位置：** 第 4.4 节，覆盖第 4.3—4.5 节。

**构成：** 目标中心球面、十二个方向锚点、周围潜在遮挡体、关系编译与固定投影，以及方向—距离查询、生存曲线和九点区域统计。球面表达方向，不是体素网格或遮挡搜索半径。

**数学标注：** $F_i=\Phi^+A_i$、$t=\log(1+\ell/\rho_i)$、$S_i(\boldsymbol\omega,0)=1$ 和 $s_i\in\mathbb R^4$。七个原始参数对应一个无命中质量、两个混合权重、两个位置参数和两个尺度参数，不是七个距离区间。

**图注：** 方向生存场的编译与查询。潜在遮挡关系经共享编译器生成方向响应 $A_i$，固定一阶方向投影得到 $F_i$。任意目标到查询点的单位方向 $\boldsymbol\omega$ 与距离 $\ell$ 经解析函数得到生存响应。该响应在固定方向上关于距离单调不增，并在零距离处为一。圆盘中心及八个圆周支持点的响应汇总为 $s_i$，作为最终可见性预测的区域特征。曲线示意表示函数结构，不表示实测遮挡概率。

主结果表注给出 **CNOR = Candidate-Normalized Occlusion Recall** 与 **WR = Weighted Recall**。CNOR 先按 pose 候选数归一化剔除量与负样本机会，避免候选绝对规模主导评价；WR 按采样区域内的最大屏幕贡献衡量可见内容保留。Useful Cull 与 Bad Cull 的分母为候选总量，普通召回率的分母为可见单元量。表头注明 aggregate、pose-macro 或 scene-equal 层级。
