# Manuscript Workspace

Do not freeze full manuscript prose yet.

Recommended workflow:

1. Stabilize each `docs/*.md` reasoning document.
2. Freeze evidence in `docs/12-evidence-status.md`.
3. Create `main.tex` only when section claims are stable.
4. Draft sections in this order:
   - Related Work
   - Problem Formulation
   - Method
   - Evaluation
   - Introduction
   - Abstract
   - Conclusion

Rationale:

The Introduction and Abstract should be written after the novelty boundary and experimental evidence are stable.
